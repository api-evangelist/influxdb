InfluxDB 3.11 brings performance for heavier, more complex workloads to GA When a system acts on a device’s latest reading or an asset’s current state, query speed decides how fast it can respond, and that gets harder as devices multiply and schemas widen. InfluxDB 3.11, released July 30, made performance improvements built for exactly those workloads in InfluxDB 3 Enterprise. For highly selective queries, like those for a single time series, this release is 4X faster than previous Enterprise 3 releases.
